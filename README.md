# rots-modlists

Wabbajack gallery metadata for **[Reign of the Septims](https://github.com/PastelCrows/Reign-of-the-Septims)**,
a conversion of [ARavenOfManyHats' Oblivion modding guide](https://www.nexusmods.com/oblivion/mods/54970).

`modlists.json` is what the Wabbajack gallery reads. The readme, build tooling and
everything else live in the [main repo](https://github.com/PastelCrows/Reign-of-the-Septims).
